# 2026-11-15

## 用 ebook-study-site 把 happy-llm 仓库做成学习站

- 项目本体是 Datawhale《Happy-LLM：从零开始构建大模型》Markdown 教程（docs 八章 + 前言/环境准备 + Extra-Chapter 七篇博客）。产出目录：`happy-llm_study/`，站点入口 `happy-llm_study/study_site/index.html`。
- 章节划分沿用仓库自带目录，共 17 关：导读(2)/基础(3)/核心(1)/实战(3)/进阶(1)/拓展(7)。第六章附带 readme + 6.4 偏好对齐，第八章附带 GRPO/OPD/Search-R1/ReTool 四个子 README，作为该章源文件合并。
- 原文是多文件且超长（第八章 122KB），技能自带 extract_ebook.py 只吃单文件，因此写了 `prepare_sources.py`：按 markdown 小节抽取标题 + 每节开头散文（跳过代码块），生成 chapters.json 与 sources/chNN.md，保证总结覆盖全章而非只看前 20000 字符。
- 内容生产：4 个并行子代理分批写卡片 → `parts/partA-D.json`；`validate.py` 独立校验元数据一致、金句逐字出自原文摘录、题目结构与 answer 下标（结果 0 错 0 警）；`assemble.py` 合并为 `study_data.json`（17 章 / 34 题 / 34 条金句）；再由技能 `build_site.py` 生成静态站。
- 规范坑：`overall_summary` 上限 400 字按字符数计，中英混排容易超，需压缩到 400 以内（最终 394）。
- 站点浅色中文界面、纯静态可离线，学习进度与答题记录存 localStorage，重建不丢进度。
