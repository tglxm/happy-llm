《Happy-LLM》是 Datawhale 的 LLM 教程，按「原理 → 实现 → 应用 → 前沿」展开。前四章从 NLP 任务与文本表示讲到注意力、Transformer 与位置编码，对比 BERT、T5、GPT/LLaMA 三类预训练架构，并给出 LLM 的涌现能力与 Pretrain–SFT–RLHF 范式。第五、六章动手：从零实现 LLaMA2（RMSNorm、RoPE、GQA）、训练 BPE 分词器、预训练并微调小模型；再用 Transformers、DeepSpeed 走通 SFT 与 LoRA。第七章讲评测、RAG 与 Agent；第八章进入 Agentic RL，覆盖 GRPO、在线蒸馏、Search-R1 与 ReTool 的多轮工具 rollout。七篇拓展博客补充词元化、解码与思维预算等专题。全书强调理论落到代码：按章配独立环境，先跑通小模型再扩规模。

  • 技术主线：文本表示 → 注意力/Transformer → 预训练语言模型 → 大语言模型，Decoder-Only 成为当代 LLM 主流架构。
  • 训练三段式：Pretrain 用海量文本学语言与知识，SFT 用指令数据学对话格式与任务能力，RLHF/RL 用偏好或可验证奖励对齐推理行为。
  • 实现抓手：RMSNorm + RoPE + GQA 构成的 LLaMA2 结构、BPE 分词器、SFT 的 loss_mask、Trainer/DeepSpeed 分布式训练与 LoRA/QLoRA 参数高效微调。
  • 应用落地：评测数据集与榜单判断能力边界，RAG 用向量库给模型补外部知识，Agent 靠工具调用把语言模型变成执行体。
  • 前沿的关键细节：GRPO 用组内相对优势省掉 Value Model，OPD 借 Reverse KL 提供逐 token 信号，多轮工具训练靠 observation mask 与 token 连续性保证梯度只落在模型动作上。
  • 学习方法：每章单独建环境，先在小模型和小数据上跑通全流程、看清数据形状，再逐步扩大规模并对照原文代码调试。

第一章 NLP 基础概念

本章铺垫 NLP 基础。它让计算机理解、解释、生成人类语言，文本表示则是决定系统性能的关键。梳理演进：从战后依赖字典规则的早期翻译，到符号主义与统计方法之争、统计模型取代手写规则，再到循环网络、注意力机制，以及词向量和预训练模型两次浪潮。随后逐一介绍分词、子词切分、词性、分类、实体、关系、摘要、翻译、问答等任务，并区分抽取式与生成式摘要。后半章聚焦文本表示：向量空间模型用词频权重却有稀疏与维数灾难，统计语言模型靠前词假设难捕捉长距离依赖，词向量产出低维密集向量仍限于局部上下文，ELMo 用双向网络和预训练实现一词多义的动态词向量。结论是表示越能保留语义与上下文性能越强，代价是复杂度上升。

第二章 Transformer 架构

本章是重要理论基础，目标是手搓可计算的 Transformer。开篇指出循环网络因依序计算难以并行，由此引出注意力机制：用查询、键、值按相关性给各值加权求和。自注意力让三者同源于一个输入的不同参数矩阵，拟合词元两两关系；掩码自注意力遮蔽未来信息以兼顾并行；多头注意力用多组参数拟合不同关系后拼接。随后解析编码器与解码器：原模型六层堆叠，每层含多头注意力、前馈网络、层归一化和残差连接，解码器另有以编码器输出为键值的交叉注意力。最后补上词嵌入与正余弦位置编码弥补词序丢失，用前置归一化稳定训练，末端以线性层、Softmax 和交叉熵算损失。结论是仅靠注意力即可摆脱循环与卷积网络，成为后续模型的基础。

第三章 预训练语言模型

本章按所用组件把预训练语言模型分为三类。编码器一脉以BERT为核心：堆叠编码器、用掩码语言模型等任务预训练、顶层加分类头适配理解任务，确立预训练加微调范式；RoBERTa去掉下一句预测、扩大语料与批量、换更大词表；ALBERT反向做减法，用嵌入分解与跨层参数共享大幅压缩参数，并改用句序预测任务。编解码器一脉的T5针对预训练与微调不一致、长度受限的问题，把各类任务统一成文本到文本并加任务前缀。解码器一脉的GPT用因果语言模型走向第三代，LLaMA沿用其架构并引入分组查询注意力，GLM以后置归一化和自回归空白填充结合两种预训练思想。结论是仅用解码器的架构成为当今大模型主流基座。

第四章 大语言模型

本章界定大语言模型：架构与因果语言模型任务沿用预训练模型，但参数达数百亿、在数万亿词元上分布式预训练，真正判据是涌现能力，第三代GPT被视为开端。核心能力有四：规模触发的涌现、上下文学习（不更新参数，靠指令与少量示例完成任务，把范式推向提示工程）、指令微调带来的指令遵循，以及靠思维链的逐步推理。特点上，多语言是海量语料的副产品，长文本靠旋转位置编码外推，多模态靠适配器与图像编码器，幻觉则是固有缺陷，提示约束与检索增强只能减弱。训练分三阶段：预训练用海量无监督语料注入知识，有监督微调激发能力、多轮对话完全来自该阶段且只对回复算损失，人类反馈强化学习借奖励模型对齐价值观，做到安全有用无害。

第七章 大模型应用

本章讲大模型落地的三大技术：评测、RAG 与 Agent。评测说明标准化衡量能暴露偏见与鲁棒性弱点，介绍 MMLU、GSM8K 等数据集，以及开放式榜单、真实用户对话竞技场、面向中文的 OpenCompass 与金融、安全、法律、医疗等垂直榜单。RAG 为缓解幻觉和知识过时，先从外部文档检索相关片段再交给模型生成，Tiny-RAG 由文档切分、向量化、向量数据库与大模型模块组成，流程为索引、检索、生成。Agent 以大模型为大脑，具备规划、记忆和工具调用能力，分任务导向型与规划推理型，并用工具接口构造 Tiny-Agent。结论是评测给选型标准，RAG 补知识可信度，Agent 补行动力。

微调 0.6B 小模型有什么意义？

本章回答现实问题：大模型 API 已足够强，为何还微调 0.6B 小模型。作者用三问决策——数据是否敏感、任务是否刚需推理链、API 并发与资金消耗：敏感数据应本地部署，简单高并发任务微调小模型以省钱，只有困难且刚需推理链才用 API 以免上下文爆显存。案例是从投诉文本抽取姓名、住址、邮箱与投诉问题，几百万条数据调大模型要花几万块且不能出外网，故微调 Qwen3-0.6B 兼顾高并发、不泄漏、效果与省钱。随后给出 SFT 数据格式、Qwen3 模板、LoraConfig、训练参数与 SwanLab 记录等实操链路。结论是选型应由数据、任务与成本决定，而非一味求大。

Transformer 整体模块设计解读

本章结合 PyTorch 源码从整体设计拆解 Transformer 各模块。因模型对词序不敏感，须把位置向量加到输入嵌入；位置编码要满足确定性、相对关系一致性和泛化能力，故用正余弦函数使偏移位置可写成已知位置的线性组合，从而推广到更长句子，并靠残差连接把位置信息传到深层。接着梳理顶层五个参数与四个类的模块化结构，前向过程区分填充掩码与上三角的因果掩码，点明模型本质是按词自回归解码。再讲多头注意力把 512 维拆成八个 64 维头、前馈网络先升维到 2048 再降回 512、解码器交叉注意力以编码器输出为键值，最后落到缩放点积注意力除以根号维度以稳定 Softmax、输出为值的加权和。

文本数据处理详解

本章梳理大模型文本数据处理的完整流水线。文本是分类数据、网络无法直接处理，需先用词嵌入把离散词语映射为连续向量，让语义相近的词在空间里更靠近。随后讲分词：在空白与标点处切分、通常不转小写以保留专有名词信息；再构建词汇表，把唯一标记按字母序编码成整数 ID，并用特殊标记处理未知词与文本分隔。针对表外词报错，重点介绍 GPT 采用的 BPE，借 tiktoken 把生词拆成子词。预训练按「下一个词预测」用滑动窗口生成输入-目标对，步长决定样本重叠程度。最后用嵌入层把 ID 查表成向量，叠加同维绝对位置嵌入，弥补自注意力不感知词序的缺陷。

本章记录把超小多模态模型接上中文能力的实战：SmolVLM2 视觉理解强却看不懂中文，作者于是用国产 GPU 把视觉模块与 Qwen3-0.6B 拼接做对齐微调。其视觉特征与文本向量直接拼接进语言模型、无交叉注意力，能复用已有语言模型。拼接三步是兼容上下文格式、整体替换文本部分与语言头、重建对齐 Qwen3 维度的映射层。对齐阶段冻结视觉与文本模型，仅训练映射器与语言头；文本长度统一 2K 且不能短于图像 token，损失掩码只算模型回复。结果仅采样少量数据即收敛，模型既看懂图片与中文，又保留 Qwen3 原有的函数调用与推理能力。

S1: Thinking Budget with vLLM

本章介绍用 vLLM 复现 s1 论文的测试时间缩放：通过设定思考预算控制推理时长，预算增加时性能明显提升。论文用大模型答题判定难易，消融发现未达预算时插入 Wait! 等特定词能引导更深入思考，「Wait, Wait」效果最好。实现上先算输入 token 数把预算换算为每轮最大生成量并设置停止符；每轮生成后把文本拼回输入、末尾追加 Wait! 迫使继续思考，思考 token 超预算即停止；达到预算后再让模型总结输出答案。实测发现插入 Wait! 未必带来多路径尝试或反思，反而可能重复生成、超出预算，推测与测试模型仅 14B 有关，强行引导甚至会让模型「一条道走到黑」。

CDDRS：细粒度语义增强的 RAG 检索

本章从零实现一套建筑文档智能 RAG 审查系统，演示知识引导检索的原理。人工审查条文主观易错，通用大模型缺建筑知识又易幻觉；传统 RAG 还因固定分块在句中截断造成知识缺失、整句问询嵌入匹配又缺少细粒度特征识别。系统先搭好基础模块，再按相邻句子语义差异度动态划分知识块以保持语义连贯。核心是知识引导检索三步：句子级编码算初始相似度、提取查询关键信息并结合文档长度自适应因子对每个块细评分、用大模型重排序并增强查询；评分融合术语重要性、稀有度与滑动窗口连贯性指数，最终按 λ 加权融合知识级与句子级结果，建筑场景常取 0.5。流程还含双阶段提示生成审查问题、偏差检测与修订建议生成。

大模型生成 Token 的方式有哪些？

本章对比大模型生成 Token 的四种解码方式。贪婪解码每步取概率最大的 token，最快且确定，却易陷局部最优、易重复，适合确定性任务。采样解码按概率分布随机抽取，用 Temperature 缩放 logits（越大越平滑、越小越尖锐、趋近 0 等价贪婪）并配合 Top-k 只留概率最高的 k 个候选，代价是需调参、结果不确定。束搜索每步维护多条候选路径并按累积对数概率筛选，束宽为 1 时等价贪婪，越大质量越高但开销越大。投机解码用小模型先写草稿、大模型批量验证并握有否决权，可减少九成以上大模型前向传播而不降低质量，本质是用计算资源换时间，草稿通常 2 到 10 个 token。
