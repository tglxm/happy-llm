学习与环境准备

SUMMARY · 章节总结

本章是导读与环境准备，核心是按章节分别准备依赖，不在同一环境装全部依赖，以减少版本冲突。教程以阅读为主、实践为辅：前四章偏原理，先通读正文再选择性复现代码；后四章偏工程，须结合代码目录与各自依赖文件。分章说明指出第二章手写 Transformer 用 CPU 或单卡，第六章用训练框架建议多卡，第八章靠 PyTRIO 远端采样只需本地 CPU 和联网。通用准备要求不同章节各建独立虚拟环境，并给出第六章从读说明、下载模型到小样本调试再到完整训练的顺序，以及第八章按量计费与代码执行隔离的提示。结论是没有多卡也能用小样本单卡调试掌握流程，动手起点可按兴趣选第五章或第六、七章。

KEY POINTS · 核心要点
  • 教程主张按章节分别准备依赖、各建独立虚拟环境，不提供统一根目录 requirements.txt，以减少版本冲突。
  • 第 2~7 章推荐 Python 3.10/3.11，第 8 章配套代码用 Python 3.13 并通过 ./chapter8/requirements.txt 固定 PyTRIO 等依赖。
  • 第六章实践顺序为 readme.md → download_model.py → download_dataset.py → 小样本调试 pretrain.py/finetune.py → pretrain.sh/finetune.sh 完整训练，且 autodl-tmp 路径、显卡编号、DeepSpeed 参数需按本地环境调整。
  • 第八章用 PyTRIO 在远端完成模型采样、logprob 计算、LoRA 前向反向与参数更新，本地只需 CPU 与联网，但需 TRIO 账号与额度并按用量计费。
  • ReTool 会在本地执行模型生成的 Python 代码，sandbox.py 无法提供可信隔离，需用一次性容器或低权限虚拟机并移除 API Key、SSH 与云凭证。
  • 第八章实践建议先跑 GRPO 与 OPD 同步版，再进入 Search-R1、ReTool 多文件 Agentic RL 工程，可用 --swanlab-mode disabled 关闭远端实验记录。

Q2. 第八章为什么把采样与训练放到 PyTRIO 远端、并特意给出费用与安全两条提示？本地程序究竟承担什么工作？

因为采样、logprob 计算、LoRA 前向反向与参数更新都由 PyTRIO 远端按用量计费完成，本地只需 CPU、稳定网络与额度，所以提示先用单步、小 batch、短轨迹确认链路再扩大规模；而 ReTool 会在本地执行模型生成的 Python 代码，sandbox.py 无法可信隔离，故需隔离环境并清除凭证。本地程序负责数据处理、搜索环境、代码执行环境与训练调度，Search-R1 还依赖联网搜索。
