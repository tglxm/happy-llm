前言

SUMMARY · 章节总结

前言以 ChatGPT 问世为起点，梳理 NLP 从符号主义、统计学习、深度学习到预训练模型、大模型阶段的演进。核心论点是 LLM 并非凭空出现，而是预训练语言模型的衍生成果：它以注意力机制和预训练加微调、靠海量无监督文本自监督预训练获得理解力，再靠扩大参数与数据规模、引入指令微调和人类反馈强化学习取得突破。由此大模型具备涌现能力以及上下文学习、指令理解和文本生成能力，用少量示例即可媲美大规模微调的效果。给读者的建议说明全书结构：前四章讲基础原理，后三章讲动手实战，并强调需具备编程与深度学习基础、理论结合实践、多复现代码、参与开源共建。结论是鼓励读者投入大模型开发浪潮。

KEY POINTS · 核心要点
  • LLM 被定位为 PLM 的衍生成果；PLM 以注意力机制为架构，靠「预训练-微调」在海量无监督文本上做自监督预训练。
  • 传统 PLM 仍依赖一定量有监督数据做下游微调、生成任务性能不尽如人意；LLM 则通过扩大参数与数据规模并引入指令微调、人类反馈强化学习实现突破。
  • LLM 具备涌现能力，以及上下文学习、指令理解、文本生成能力，可用少量监督示例达到媲美大规模微调 PLM 的性能。
  • 全书前四章是基础知识：第 1 章 NLP 任务与发展、第 2 章 Transformer（含原理与代码实现）、第 3 章 PLM 的 Encoder-Only / Encoder-Decoder / Decoder-Only 三种架构、第 4 章 LLM 特点与训练过程。
  • 第 5~7 章为实战：基于 PyTorch 亲手搭建 LLM 并做预训练与 SFT、用 Transformers 框架高效训练、以及评测、RAG、Agent 应用。
  • 作者建议读者具备 Python 编程、深度学习与 NLP 术语基础，理论结合实际、复现代码并参与 Datawhale 等开源社区。
「LLM 其实是 NLP 领域经典研究方法预训练语言模型（Pretrain Language Model，PLM）的一种衍生成果。」
「相较于传统 PLM，LLM 具备涌现能力，具有强大的上下文学习能力、指令理解能力和文本生成能力。」
实践建议：按前言给出的地图给自己定阅读顺序：先通读第 2 章 Transformer 的原理与代码实现，再对第 3 章 Encoder-Only / Encoder-Decoder / Decoder-Only 三种架构各找一个代表模型（如 BERT、GPT）对照，确认能说清 PLM 到 LLM 的差别后再进入实战章节。

Q1. 关于 PLM 与 LLM 的关系，下列哪一项符合前言的论述？

💡 前言明确 LLM 是 PLM 的衍生成果，突破来自扩大规模加指令微调、人类反馈强化学习；涌现能力、上下文学习等是 LLM 相对传统 PLM 的新特性，而传统 PLM 仍依赖一定量有监督数据做下游微调、生成任务性能并不理想，故 A、B、D 都与原文相悖。
