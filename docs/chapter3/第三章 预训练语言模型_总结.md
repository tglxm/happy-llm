# 第三章 预训练语言模型 · 内容总结

> 原文：[第三章 预训练语言模型.md](./第三章%20预训练语言模型.md)

本章以 Transformer 的 Encoder、Decoder 为起点，梳理了预训练语言模型（PLM）的三条技术路线，以及各自代表模型的架构、预训练任务、训练规模和发展脉络。

## 0. 一页速览

| 架构 | 代表模型 | 核心预训练任务 | 擅长方向 | 关键特征 |
| --- | --- | --- | --- | --- |
| Encoder-only | BERT、RoBERTa、ALBERT | MLM（+ NSP/SOP） | NLU：分类、匹配、推理、序列标注 | 双向语义、`<CLS>` 句级表示、预训练+微调 |
| Encoder-Decoder | T5 | MLM（BERT-style） | NLG 与 Seq2Seq：翻译、摘要、问答 | 文本到文本大一统、任务前缀、RMSNorm |
| Decoder-only | GPT、LLaMA、GLM | CLM（GLM 为空白填充） | NLG、通用生成、LLM 基座 | 掩码自注意力、自回归生成、规模化扩展 |

三条路线的共同基础是 **预训练 + 微调**：先在海量无监督语料上学习通用语言能力，再以少量标注数据适配下游任务。

---

## 1. Encoder-only PLM

### 1.1 BERT

**定位**：Google 2018 年发布，将 Transformer Encoder 堆叠并配合新预训练任务，统一了 NLU 任务，确立了“预训练 + 微调”范式。

**思想沿承**

- 沿用 Transformer 架构，只取 Encoder 部分。
- 沿用 ELMo 开启的“预训练 + 微调”思路，并用 Transformer 与 MLM 将其推向主流。

**模型结构**

- 组成：`Embedding → N × Encoder Layer → prediction_heads`。
- 规模：
  - BERT-base：12 层 Encoder，隐藏维度 768，约 110M 参数。
  - BERT-large：24 层 Encoder，隐藏维度 1024，约 340M 参数。
- 分词：WordPiece，子词切分；中文通常以单字为 token。
- Encoder Layer：自注意力 + 残差 + LayerNorm，再接 Intermediate 层（线性层 + 激活函数）。
- 激活函数：GELU，将随机正则思想引入激活函数。
- 位置编码：原始 BERT 使用绝对位置编码；本章介绍的改进版将可训练的**相对位置编码**融入注意力，表达更丰富，但参数更多，且最大上下文固定为 512 token。
- 输出头 `prediction_heads`：线性层 + 激活函数，最后一维等于任务类别数，经 Softmax 得到类别概率。

**预训练任务**

- **MLM（掩码语言模型）**：模拟“完形填空”，随机遮蔽部分 token，利用上下文预测被遮蔽 token，从而学习双向语义。
  - 选取 15% 的 token 参与预测。
  - 其中 80% 替换为 `<MASK>`，10% 替换为随机 token，10% 保持不变。
  - 保留 10% 不变用于缓解预训练与微调的不一致；随机替换迫使模型保持上下文表征能力。
- **NSP（下一句预测）**：判断两个句子是否为连续上下文，训练句级语义关系，适配问答匹配、自然语言推理等任务。
  - 正样本来自连续句对，负样本来自打乱后的句对，数据几乎无限。
- 训练数据：BooksCorpus 800M 词 + 英文维基百科 2500M 词，共约 13GB、3.3B token。
- 训练设置：90% 数据用 128 长度、10% 用 512 长度；batch size 256，训练 1M 步（约 40 个 Epoch）。
- 算力：base 用 16 块 TPU、large 用 64 块 TPU，训练约 4 天。

**下游微调**

- 输入首部加入 `<CLS>`，其编码作为整句语义表示，NSP 分类器即使用该向量。
- 文本分类：替换 `prediction_heads` 分类头。
- 序列标注：融合多层隐状态后输出标注。
- 文本生成：直接取 Encoder 输出解码。
- 微调使用少量标注数据、较小 batch size，参数更新幅度更小。

**意义**：发布即在 11 项 NLP 任务上取得 SOTA，是 NLU 方向的统治性模型；在数据充足、强调高吞吐的 NLU 场景中，至今仍具实用性。

### 1.2 RoBERTa

**定位**：Facebook 提出，模型架构与 BERT-large 完全一致，通过训练策略优化刷新多项 SOTA。

**三项优化**

1. **去掉 NSP**
   - 设计四组对照实验：段落级 MLM+NSP、文档对 MLM+NSP、跨文档 MLM、单文档 MLM。
   - 后两组（无 NSP）显著更优，单文档 MLM 微调效果最佳，因此最终只保留 MLM。
   - 同时将静态 Mask 改为**动态 Mask**：每个 Epoch 重新随机遮蔽，训练数据更丰富；动态遮蔽略优且更高效，之后成为 MLM 的主流做法。
2. **更大数据与训练步长**
   - 数据从 13GB 扩展到 160GB，增加 CC-NEWS、OPENWEBTEXT、STORIES，约为 BERT 的 10 倍。
   - batch size 提升到 8K；在相同 3.3B token 下性能已更好。
   - 共训练 500K 步（约 66 个 Epoch），全部使用 512 长度。
   - 使用 1024 块 V100（32GB）训练约 1 天。
3. **更大词表**
   - 分词从 WordPiece 改为 BPE（字节对编码），以子词对为单位。
   - 词表从 30K 扩大到 50K，提升编码能力，同时增加 Embedding 参数。

**结论**：更大数据、更大 batch、更长训练步长能持续提升性能，这为后续 LLM 的规模化提供了依据。

### 1.3 ALBERT

**定位**：同样基于 BERT 架构，但目标是**减少参数、保持甚至提升能力**。

**三项优化**

1. **Embedding 参数分解**
   - 原 Embedding 参数量为 `V × H`（词表 × 隐藏维度），隐藏维度增大时膨胀明显。
   - 将词向量维度与隐藏维度解绑：先输出 `E = 128` 维，再经 `E × H` 线性矩阵升维。
   - 参数量变为 `V × E + E × H`，当 `E << H` 时显著减少。
2. **跨层参数共享**
   - 只初始化一层 Encoder，但前向仍计算 24 次，所有层共享同一套参数。
   - 可构建“更宽但更小”的模型：24 层、隐藏维度 2048 的 ALBERT-xlarge 仅约 59M 参数，效果优于 334M 的 BERT。
   - 局限：计算次数并未减少，训练和推理速度反而更慢，这也是 ALBERT 未能取代 BERT 的重要原因。
3. **SOP 预训练任务**
   - 认为 NSP 过于简单，但选择“加难”而非删除。
   - 正例仍是连续句对；负例改为将同一对句子的顺序交换。
   - 模型不仅要判断句子关系，还要学习顺序关系。
   - 效果：MLM + SOP > 仅 MLM > MLM + NSP。

**其他 BERT 系模型**：改进预训练任务的 ERNIE、蒸馏小模型 DistilBERT、多语言模型 XLM 等。

## 2. Encoder-Decoder PLM：T5

**定位**：Google 的 Text-To-Text Transfer Transformer，保留完整 Encoder-Decoder，把所有 NLP 任务统一为“文本到文本”。

**模型结构**

- 组成：Tokenizer + Transformer（EncoderLayers + DecoderLayers）。
- 每个 Block 包含多头注意力、前馈神经网络和 Norm 层，可像积木一样增减层数。
- Decoder 额外包含 **Encoder-Decoder Attention**，用于捕捉输入与输出序列之间的依赖；它与 Self-Attention 结构几乎一致，主要差异在位置编码和 Mask。
- 归一化采用 **RMSNorm**：用均方根归一化，只有可学习的缩放参数 `γ`，比 LayerNorm 更简单。

$$
\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{n}\sum_{i=1}^{n}x_i^2 + \epsilon}} \cdot \gamma
$$

- 使用相对位置编码处理长序列位置信息。

**预训练任务**

- 任务：MLM（BERT-style），随机遮蔽 15% 的 token 并预测。
- 数据：自建 **C4**（Colossal Clean Crawled Corpus）数据集，约 750GB，从 Common Crawl 清洗得到。
- 输入输出均转为“文本到文本”格式。
- 还尝试多任务混合预训练，以学习更通用的语言表示。
- 预训练完成后，在任务数据上微调并调整解码策略。

**大一统思想**

- 所有任务统一为 `输入文本 → 输出文本`：
  - 分类：`classify: 这是一个很好的产品` → `正面`
  - 翻译：`translate English to French: How are you?` → `Comment ça va?`
- 输入前加任务前缀，如 `summarize:`、`translate English to German:`。
- 价值：简化模型设计与训练流程，提升多任务泛化与复用性。

## 3. Decoder-only PLM

Decoder-only 是当前 LLM 的主流基座架构（RWKV、Mamba 等非 Transformer 架构除外）。

### 3.1 GPT

**定位**：OpenAI 2018 年发布，最早明确提出通用“预训练 + 微调”思想的模型，选择 Decoder-only，更契合 NLG。

**模型结构**

- 流程：`input_ids → Embedding → Positional Embedding → N × Decoder Layer → 线性层映射到词表`。
- 位置编码：沿用 Transformer 的经典 **Sinusoidal 绝对位置编码**（区别于 BERT 的可训练位置编码）。
- 第一代 GPT 使用 12 层 Decoder。
- Decoder 层更像 Encoder 层：
  - 没有 Encoder 输入，因此只保留一个**掩码自注意力**层，不再有交叉注意力。
  - LayerNorm 从注意力之后移到注意力之前（Pre-Norm）。
  - 掩码矩阵遮蔽未来 token，使每个 token 只能关注之前的 token。
- MLP 使用两个一维卷积核提取特征（效果与线性层差别不大）。

**预训练任务：CLM**

- 因果语言模型：根据序列中前面所有 token 预测下一个 token，不断重复以生成完整文本。
- 属于“补全”形式，与人类书写习惯一致，也与下游生成任务一致。
- 无需标注，可直接用于任何自然语言文本，适合大规模预训练。

**GPT 系列发展**

| 模型 | Decoder 层数 | Hidden size | 注意力头数 | 注意力维度 | 总参数量 | 预训练语料 |
| --- | --- | --- | --- | --- | --- | --- |
| GPT-1 | 12 | 3072 | 12 | 768 | 0.12B | 5GB |
| GPT-2 | 48 | 6400 | 25 | 1600 | 1.5B | 40GB |
| GPT-3 | 96 | 49152 | 96 | 12288 | 175B | 570GB |

- **GPT-1**：首个 Decoder-only 预训练模型，12 层、768 隐藏维度、0.12B 参数，BooksCorpus 5GB。规模与 BERT-base 相当，但表现略逊。
- **GPT-2**：48 层、1600 隐藏维度、1.5B 参数，自建 WebText 40GB；将 Post-Norm 改为 Pre-Norm 以稳定深层梯度；以 **zero-shot** 为目标，不微调直接完成任务。
- **GPT-3**：175B 参数，从 CC、WebText、维基百科采样 45T token、清洗后 570GB；使用稀疏注意力；提出 **few-shot / 上下文学习（In-context Learning）**，在 prompt 中给出 3~5 个示例即可显著提升表现。
- **ChatGPT**：在 GPT 系列基础上引入“预训练 → 指令微调 → 人类反馈强化学习（RLHF）”三阶段训练，引爆大模型热潮。

### 3.2 LLaMA

**定位**：Meta 的 Decoder-only 系列，是当前开源 LLM 的普遍基座，整体结构与 GPT 类似。

**模型流程**

1. 文本经 tokenizer 转为 input_ids。
2. Embedding 映射为词向量，Positional Embedding 注入位置信息，得到 hidden_states。
3. 依次通过多个 Decoder Block：
   - Masked Self-Attention：由 hidden_states 线性变换得到 Q、K、V，计算注意力分数并加权求和。
   - MLP：两层全连接，先映射到中间维度并经激活函数，再映射回原维度。
4. 经线性层映射到词表维度，得到下一个 token 的概率分布，再采样或贪婪解码。

**版本演进**

- **LLaMA-1（2023.02）**
  - 7B、13B、30B、65B 四个版本。
  - 预训练语料超过 1T token；65B 使用 2048 块 A100 80G 训练约 21 天。
  - 凭借开源与性能迅速成为社区热门基座。
- **LLaMA-2（2023.07）**
  - 7B、13B、34B、70B，除 34B 外均开源。
  - 语料扩展到 2T token，上下文长度从 2048 翻倍到 4096。
  - 引入分组查询注意力（GQA）。
- **LLaMA-3（2024.04）**
  - 8B、70B 两个版本（400B 版本当时仍在训练）。
  - 支持 8K 长文本；tokenizer 词表扩大到 128K，编码效率更高。
  - 预训练语料超过 15T token，约为 LLaMA-2 的 7 倍。

### 3.3 GLM

**定位**：智谱的中文 LLM 系列，包括 ChatGLM1/2/3 与 GLM-4；ChatGLM-6B 是 2023 年国内最早的开源中文 LLM 之一，也是最早提出区别于 GPT、LLaMA 架构的 LLM。

**相对 GPT 的三点架构差异**

1. **Post-Norm**：先残差再 LayerNorm，参数正则化更强、鲁棒性更好；主流 LLM（GPT、LLaMA）则使用 Pre-Norm。GLM 论文认为 Post-Norm 可避免数值错误。
2. **单线性层输出**：最终 token 预测只用一个线性层，而非 MLP，减少输出端参数，把参数留给模型主体。
3. **GeLUs 激活**：从 ReLU 改为 GeLU 类激活，对接近 0 的正向传播做非线性映射，输出更连续。

**预训练任务：GLM（通用语言模型）**

- 结合自编码（MLM）与自回归（CLM）思想。
- **自回归空白填充**：随机遮蔽**连续的一段 token**，而非 MLM 的单个 token。
- 模型既利用遮蔽段前后的上下文预测内容，又在遮蔽段内部按 CLM 方式顺序重建。
- 示例：
  - 输入：`I <MASK> because you <MASK>`
  - 输出：`<MASK> - love you; <MASK> - are a wonderful person`
- 优点：既适配逐 token 生成任务，又迫使模型从双向学习语义，适配理解任务；同体量下曾优于 BERT 系模型。
- 局限：进入 LLM 时代后，超大规模预训练下 CLM 的优势远超 MLM，ChatGLM2 起回归 CLM。

**GLM 家族**

- **ChatGLM-6B（2023.03）**：1T 语料预训练，2K 上下文，国内中文 LLM 的重要起点。
- **ChatGLM2-6B（2023.06）**：上下文扩展到 32K；架构基本回归 LLaMA，引入 MQA，预训练任务回归 CLM。
- **ChatGLM3-6B（2023.10）**：架构相对二代未变，主要靠更多样数据、更充分训练与更优策略；支持函数调用与代码解释器，便于 Agent 开发。
- **GLM-4（2024.01）**：支持 128K 上下文；开源轻量版 GLM-4-9B，1T 多语言 token、8K 上下文，训练算力更少但超过 Llama-3-8B，并支持 GLM-4 的全部工具能力。

## 4. 横向对比

| 模型 | 架构 | 预训练任务 | 位置编码 | 归一化 | 代表性贡献 |
| --- | --- | --- | --- | --- | --- |
| BERT | Encoder-only | MLM + NSP | 原始为绝对位置编码，改进版为可训练相对位置编码 | LayerNorm | 确立预训练+微调范式，统一 NLU |
| RoBERTa | Encoder-only | MLM（动态 Mask） | 同 BERT | LayerNorm | 证明更大数据、更大 batch、更长训练的价值 |
| ALBERT | Encoder-only | MLM + SOP | 同 BERT | LayerNorm | Embedding 分解、跨层参数共享、SOP |
| T5 | Encoder-Decoder | MLM（BERT-style） | 相对位置编码 | RMSNorm | 文本到文本大一统 |
| GPT | Decoder-only | CLM | Sinusoidal 绝对位置编码 | 由 Post-Norm 改为 Pre-Norm（GPT-2） | 通用预训练、zero-shot、few-shot/ICL |
| LLaMA | Decoder-only | CLM | 位置编码（章节未展开具体类型） | Pre-Norm | 开源 LLM 基座、GQA、长上下文、大词表 |
| GLM | Decoder-only | GLM（自回归空白填充） | 同 GPT 系 | Post-Norm | MLM 与 CLM 融合、中文开源 LLM |

## 5. 演进脉络

1. **架构**：Encoder-only（理解）→ Encoder-Decoder（统一 Seq2Seq）→ Decoder-only（生成与通用 LLM 主流）。
2. **预训练任务**：MLM/NSP → T5 的 BERT-style MLM → GLM 空白填充 → CLM 成为 LLM 时代主流。
3. **模型规模**：百 M（BERT）→ 千 M（GPT-2）→ 百 B（GPT-3）→ 万亿级 token 预训练（LLaMA-3 超 15T）。
4. **使用范式**：预训练+微调 → zero-shot → few-shot/上下文学习 → 预训练 + SFT + RLHF。
5. **工程优化**：Post-Norm → Pre-Norm（GPT-2 起）；T5 采用 RMSNorm；词表从 30K 的 WordPiece 扩展到 50K 的 BPE（RoBERTa），再到 128K（LLaMA-3）；注意力引入 GQA/MQA 以降低推理成本。

## 6. 术语速查

- **MLM**：掩码语言模型，随机遮蔽 token 并利用双向上下文预测。
- **NSP**：下一句预测，判断句对是否为连续上下文。
- **SOP**：句子顺序预测，正例为连续句对，负例为交换顺序后的句对。
- **CLM**：因果语言模型，根据前文自回归预测下一个 token。
- **GLM**：通用语言模型任务，对连续 span 做自回归空白填充，融合 MLM 与 CLM。
- **zero-shot / few-shot**：不提供示例 / 在 prompt 中提供少量示例完成任务。
- **In-context Learning**：模型从 prompt 上下文示例中学习任务方法。
- **GQA / MQA**：分组查询注意力 / 多查询注意力，减少 Key/Value 头数，降低推理开销。
- **Pre-Norm / Post-Norm**：LayerNorm 放在子层之前 / 残差之后。
- **RMSNorm**：基于均方根的归一化，仅含一个可学习缩放参数。
- **C4**：T5 使用的大规模清洗英文语料，约 750GB。

---

**一句话总结**：本章沿着“Encoder-only → Encoder-Decoder → Decoder-only”的路线，说明了预训练任务（MLM/NSP/SOP/CLM/GLM）如何塑造模型能力，以及“更大数据 + 更大模型 + 更匹配的任务”如何把 PLM 推向 LLM。
