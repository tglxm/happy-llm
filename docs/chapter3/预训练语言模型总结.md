# 预训练语言模型总结

## 一、核心概念梳理

### 1. NLU / NLG

- **NLU（Natural Language Understanding，自然语言理解）**：以“理解文本”为核心的任务，如文本分类、情感分析、命名实体识别、问答匹配、自然语言推理等。输入文本、输出 Label 或结构化结果。
- **NLG（Natural Language Generation，自然语言生成）**：以“生成文本”为核心的任务，如对话、摘要、翻译等。

### 2. LM（Language Model，语言模型）

- 经典预训练任务：根据**上文预测下一个 token**（自回归方式）。
- 优点：训练与下游生成任务完全一致；任何无标注文本都可直接使用，语料近乎无限。
- 缺点：只能拟合**从左到右的单向语义**，无法学习双向语义关系。

### 3. MLM（Masked Language Model，掩码语言模型）

- BERT 提出的预训练任务，模拟“完形填空”：随机遮蔽文本中部分 token，利用\*\*上下文（双向信息）\*\*预测被遮蔽的 token。
- 优点：能拟合双向语义，更适合 NLU 任务；同样无需人工标注。
- 训练策略：随机选 15% 的 token，其中 **80% 替换为 `<MASK>`、10% 替换为随机 token、10% 保持不变**。随机替换迫使模型对每个 token 都保留上下文表征，10% 保持不变用于消除预训练与微调的不一致。
- 缺点：预训练时存在人工 `<MASK>`，下游微调/推理时没有，导致预训练-微调不一致。

### 4. NSP / SOP（句级任务）

- **NSP（Next Sentence Prediction）**：判断两个句子是否是连续上下文，用于训练句级语义（问答匹配、NLI 等）。
- **SOP（Sentence Order Prediction，ALBERT 提出）**：正例为连续句对，负例为将两句**顺序颠倒**，难度更高，实验证明效果优于 NSP。

### 5. 预训练 + 微调范式

- 先在海量无监督语料（数十亿 token 级）上预训练获得通用语言能力，再在少量有标注数据上对下游任务微调。这一范式由 ELMo 开启、由 BERT 推向高潮，是现代 LLM 的基础。

## 二、各模型架构与特点对比

### 1. BERT（Google, 2018）— Encoder-Only

- **结构**：Transformer Encoder 堆叠 + Embedding + 顶层 `prediction_heads`（线性分类头）。Base：12 层 / 768 hidden / 110M；Large：24 层 / 1024 hidden / 340M。
- **激活函数**：GELU（高斯误差线性单元，将随机正则思想引入激活函数）。
- **位置编码**：改进版采用可训练的**相对位置编码**（融入注意力机制），但无法处理超过训练长度（512 token）的输入。
- **Tokenizer**：WordPiece。
- **预训练任务**：MLM + NSP，语料 13GB（BooksCorpus 800M + 英文维基 2500M，约 3.3B token），batch size 256，训练 1M 步（40 Epoch）。
- **微调**：输入首部加 `<CLS>` token 表示句级语义；对不同任务只需更换/微调 prediction\_heads，高效迁移到多种 NLU 任务，11 个 NLP 赛道 SOTA。

### 2. RoBERTa（Facebook）— Encoder-Only，BERT 训练优化

架构与 BERT-large 完全一致，核心改进在训练策略：

- **去掉 NSP**：实验证明 NSP 带来负面效果，只用 MLM。
- **动态 Masking**：Mask 操作移到训练阶段动态进行（BERT 是静态预 Mask，每 10 个 Epoch 数据才变化一次）。
- **更大规模预训练**：语料扩至 160GB（十倍于 BERT），加入 CC-NEWS、OPENWEBTEXT、STORIES；batch size 提升到 8K；全部用 512 长度训练；训练 500K 步（约 66 Epoch）。
- **更大 BPE 词表**：50K（BERT 为 30K），改用 BPE 分词。
- 证明“更大预训练数据 + 更大训练步长”的重要性，是 LLM 诞生的思想基础之一。

### 3. ALBERT（Google）— Encoder-Only，参数压缩

- **Embedding 参数分解**：将 Embedding 输出维度（设为 128）与隐藏层维度解耦，用一个小矩阵 `128*H` 升维，参数量从 `V*H` 降为 `V*E + E*H`。
- **跨层参数共享**：24 层 Encoder Layer 共享同一份参数，仅计算 24 次。ALBERT-xlarge（24 层、hidden 2048）仅 59M 参数，效果优于 334M 的 BERT。
- **SOP 任务**：以句序颠倒替代 NSP，效果更好。
- **不足**：参数虽少但计算量未减，训练/推理速度反而更慢，限制了其推广。

### 4. T5（Google）— Encoder-Decoder

- **大统一（Text-to-Text）思想**：将所有 NLP 任务统一为“文本到文本”的转换，分类、翻译、问答等都表示为输入文本→输出文本，简化模型设计与任务处理。
- **结构**：完整 Encoder-Decoder Transformer；Decoder 额外包含 Encoder-Decoder Attention，用于捕捉输入与输出序列间的依赖；两者仅在位置编码和 Mask 机制上不同。
- **归一化**：用 **RMSNorm** 替代 LayerNorm，仅一个可学习参数，更简单高效。
- 代表了保留完整 Transformer 结构的技术路线。

### 5. GPT 系列（OpenAI）— Decoder-Only

- 只保留 Transformer 的 Decoder 部分，沿用经典 **LM（自回归）任务**预训练。
- 通过不断增加参数量和预训练语料在 NLG 任务上取得显著优势，是当今 LLM 的基座架构。单向注意力配合因果 Mask，天然适配文本生成。

### 6. LLaMA（Meta）— Decoder-Only

- 现代开源 LLM 代表，Decoder-Only 架构 + 训练改进：RMSNorm（Pre-Norm）、SwiGLU 激活、Rotary 位置编码（RoPE），以较小参数量（7B\~65B）通过海量 token 训练（1T+ token，仅 1 个 Epoch）获得强大能力。体现了 RoBERTa 以来“数据规模 > 重复训练”的共识。

### 7. GLM（智谱）— 自回归填空（Autoregressive Blank Infilling）

- 独特的 **Encoder-Decoder 混合式单体架构**：对一段文本，部分 span 采用双向编码（类似 MLM，理解任务），部分采用自回归生成被遮蔽内容（类似 LM，生成任务）。
- 兼顾 NLU 与 NLG 能力，通过 2D 位置编码和自定义注意力 Mask 在单一 Transformer 中统一两类任务；后续 ChatGLM 系列即基于此，加入对话指令微调（SFT、RLHF）。

## 三、模型对比总表

| 模型          | 架构                        | 预训练任务                          | 位置编码/激活/分词                    | 优势                        | 局限                          |
| :---------- | :------------------------ | :----------------------------- | :---------------------------- | :------------------------ | :-------------------------- |
| **BERT**    | Encoder-Only              | MLM + NSP                      | 相对位置编码（可训练）/ GELU / WordPiece | 双向语义，NLU 之王，微调范式确立        | 预训练-微调不一致（MASK）；最长 512；不能生成 |
| **RoBERTa** | Encoder-Only（同 BERT）      | 仅 MLM（动态 Mask）                 | 同 BERT / BPE 50K 词表           | 更大数据（160GB）、更大 batch、更长训练 | 同 BERT 的架构局限                |
| **ALBERT**  | Encoder-Only              | MLM + SOP                      | Embedding 参数分解、跨层参数共享         | 参数极小（59M）且性能更强            | 计算量不减、速度慢，未取代 BERT          |
| **T5**      | Encoder-Decoder           | Text-to-Text 统一多任务             | RMSNorm / BPE                 | 大统一思想，NLU+NLG 兼顾，泛化好      | 推理需两阶段，效率低于 Decoder-Only    |
| **GPT**     | Decoder-Only              | 自回归 LM                         | 因果 Mask、单向                    | 生成能力强、Scaling 友好、LLM 基座   | 单向注意力，理解类小数据任务上可能不如 BERT    |
| **LLaMA**   | Decoder-Only              | 自回归 LM（1T+ token）              | RoPE / SwiGLU / RMSNorm / BPE | 高效强大、开源生态基石               | 同 Decoder-Only 局限           |
| **GLM**     | 单体 Encoder-Decoder（自回归填空） | Autoregressive Blank Infilling | 2D 位置编码                       | 统一 NLU 与 NLG，中文能力强        | 架构复杂，实现与生态门槛较高              |

## 四、关键结论

1. **三条技术路线**：Encoder-Only（BERT 系，擅 NLU）、Encoder-Decoder（T5/GLM，兼顾理解与生成）、Decoder-Only（GPT/LLaMA，擅 NLG，最终成为 LLM 主流）。
2. **预训练任务演进**：LM → MLM+NSP（BERT）→ 去 NSP/动态 Mask（RoBERTa）→ SOP（ALBERT）→ Text-to-Text 大统一（T5）→ 回归自回归 LM（GPT 系），反映了“训练与任务一致性”和“数据规模”的重要性。
3. **Decoder-Only 胜出的原因**：训练目标与生成式下游任务完全一致、Scaling 特性极佳、架构简单易并行，成为 LLaMA、GLM-2 之后几乎所有主流 LLM 的选择。
